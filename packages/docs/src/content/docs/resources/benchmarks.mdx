StAX-XML now benchmarks the package as a pure JavaScript parser. The benchmark
suite keeps the public API contract fixed and measures the surfaces users can
actually call from JavaScript.

## What to Run

- `pnpm --dir packages/benchmark bench:sync` measures synchronous parser and
  builder paths.
- `pnpm --dir packages/benchmark bench:async` measures async parser and writer
  paths.
- `pnpm --dir packages/benchmark bench:runtime-matrix` compares the same
  JavaScript reader workload across Node, Bun, and Deno when those runtimes are
  installed.

## Contract

Parser benchmarks return JavaScript strings and JavaScript objects. They do not
use binary parser modules or backend-mode fallbacks. Large-file checks should continue to focus on low RSS, staying below
JavaScript string-size limits, and pull-style consumption through the event,
stream, and converter APIs.
